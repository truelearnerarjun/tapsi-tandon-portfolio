# Tapsi Tandon — Official Portfolio Website

> **Anchor · Lifestyle Blogger · Entrepreneur**

The official luxury portfolio website for **Tapsi Tandon**, featuring event hosting, brand collaborations, property consulting, interviews, and visual storytelling.

---

## 🌟 Overview & Key Sections

- **Hero & Story**: Cinematic stage introduction and unfiltered journey milestones.
- **Expertise & Disciplines**: Celebrity anchoring, lifestyle blogging, entrepreneurship, and travel creation.
- **Property & Perspective**: Real estate showcase and luxury property walkthroughs.
- **Featured Media**: 
  - *Tapsi Tandon — Unfiltered* (Barkha Podcast feature)
  - *Movement & Expression* (Bollywood & stage dance feature)
- **Select Brand Collaborations**: Partnerships across leading lifestyle, retail, and corporate brands.
- **Curated Works & Honors**: Prestigious recognition including the Chhatrapati Shivaji Maharaj Award, International Anchor, and Best Celebrity Anchor.
- **From the Feed**: Symmetrical 3×2 live Instagram curation linked directly to [@tapsitandonofficial](https://www.instagram.com/tapsitandonofficial/).
- **Let's Connect**: Direct booking and collaboration contact channels.

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Design System**: Luxury dark aesthetic, custom serif typography (Cormorant Garamond), gold accents
- **Media**: Custom custom-styled video player controllers with scrubbers, volume toggles, and ambient lighting glow effects
- **Layout**: CSS Grid, Flexbox, fully responsive across mobile, tablet, and ultra-wide displays

---

## 🚀 Local Development

To run the site locally:

```bash
# Using Python
python -m http.server 8000

# Or using Node / npx
npx serve .
```

Open `http://127.0.0.1:8000` in your browser.
